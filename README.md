# Dark War:Survival

## Random BGB

![Dark War:Survival](./images/bg-B2dcFL5Z.webp)

Random BGB는 Dark War:Survival의 BGB 참여자를 무작위로 선발하는 웹 앱입니다. 전체 명단에서 선발·예비 인원을 중복 없이 뽑고, 미선발 인원까지 확인하며 각 명단을 이미지로 저장할 수 있습니다.

## 주요 기능

- 줄바꿈으로 구분한 참여 명단 입력
- 빈 줄과 이름 앞뒤 공백 제거, 같은 이름의 중복 입력 제외
- 명단 하단에 추첨 대상 인원수와 중복 제외 건수 표시
- 선발·예비 인원이 겹치지 않는 랜덤 추첨
- 선발·예비에 포함되지 않은 미선발 명단과 인원수 표시
- 선발·예비·미선발 명단을 영문 ABC순, 한글 가나다순으로 정렬
- 선발·예비·미선발 명단을 각각 PNG 이미지로 다운로드
- 같은 명단으로 성공한 추첨 횟수를 누적 표시
- 명단과 인원 설정을 현재 탭에 임시 저장하고 새로고침 시 복원
- 최대 너비 1200px의 PC·모바일 반응형 화면

## 사용 방법

1. 페이지를 열고 **전체 명단**에 한 줄에 한 명씩 이름을 입력하거나 붙여넣습니다.
2. 명단 하단의 인원수를 확인하고 **선발 인원**과 **예비 인원**을 설정합니다.
3. **랜덤 뽑기**를 누르면 선발·예비·미선발 명단이 이름순으로 표시됩니다.
4. 각 명단 아래의 **이미지 다운로드**를 눌러 PNG 파일을 저장합니다. 이미지에는 해당 명단과 동일 명단의 누적 추첨 횟수가 함께 표시됩니다.

| 구분 | 기본 인원 | 설정 범위 | 다운로드 파일 |
| --- | --- | --- | --- |
| 선발 | 20명 | 1~20명 | `random-bgb-selected.png` |
| 예비 | 10명 | 0~10명 | `random-bgb-reserve.png` |
| 미선발 | 추첨 후 남은 인원 | 자동 계산 | `random-bgb-unselected.png` |

중복을 제외한 전체 인원은 선발·예비 인원의 합계 이상이어야 합니다. 인원이 부족하거나 설정 범위를 벗어나면 안내 메시지가 표시됩니다.

각 명단의 번호는 이름순으로 정렬한 표시 순서입니다. 다시 **랜덤 뽑기**를 누르면 새로 추첨하며, 명단이나 인원 설정을 수정하면 기존 결과가 초기화됩니다. 추첨 전이나 해당 명단의 인원이 0명일 때는 이미지 다운로드 버튼이 비활성화됩니다.

미선발 명단은 전체 명단에서 선발·예비 인원을 제외한 나머지입니다. 전원이 선발·예비에 포함되면 미선발 인원이 없다고 안내합니다.

## 임시 저장

명단, 인원 설정, 명단별 추첨 횟수는 브라우저의 `sessionStorage`에 저장됩니다. 같은 탭에서 새로고침하면 복원되며, 탭의 세션이 종료되면 임시 저장도 종료됩니다. 추첨 결과는 새로고침 후 다시 뽑아야 합니다.

추첨 횟수는 성공한 추첨만 누적하며 결과 영역에 표시됩니다. 입력 순서·공백·중복만 달라진 경우에는 같은 명단으로 판단하고, 선발·예비 인원 설정을 바꿔도 횟수를 유지합니다. 참여자 구성이 다른 명단은 별도로 누적하며, 이전 명단을 다시 입력하면 해당 명단의 횟수를 불러옵니다.

입력한 명단은 브라우저 안에서 처리됩니다. 브라우저가 임시 저장을 차단하면 화면에 안내가 표시되며, 새로고침 시 입력 내용이 사라질 수 있습니다.
