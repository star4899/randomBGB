# Dark War:Survival

## Random BGB

![Dark War:Survival](./images/bg-B2dcFL5Z.webp)

Random BGB는 Dark War:Survival의 BGB 참여자를 무작위로 선발하는 웹 앱입니다. 전체 명단에서 선발·예비 인원을 중복 없이 뽑고, 결과를 각각 이미지로 저장할 수 있습니다.

## 주요 기능

- 줄바꿈으로 구분한 참여 명단 입력
- 빈 줄과 이름 앞뒤 공백 제거, 같은 이름의 중복 입력 제외
- 명단 하단에 추첨 대상 인원수와 중복 제외 건수 표시
- 선발·예비 인원이 겹치지 않는 랜덤 추첨
- 선발·예비 명단을 영문 ABC순, 한글 가나다순으로 정렬
- 선발·예비 명단을 각각 PNG 이미지로 다운로드
- 명단과 인원 설정을 현재 탭에 임시 저장하고 새로고침 시 복원
- 최대 너비 1200px의 PC·모바일 반응형 화면

## 사용 방법

1. 페이지를 열고 **전체 명단**에 한 줄에 한 명씩 이름을 입력하거나 붙여넣습니다.
2. 명단 하단의 인원수를 확인하고 **선발 인원**과 **예비 인원**을 설정합니다.
3. **랜덤 뽑기**를 누르면 선발·예비 명단이 이름순으로 표시됩니다.
4. 각 명단 아래의 **이미지 다운로드**를 눌러 PNG 파일을 저장합니다.

| 구분 | 기본 인원 | 설정 범위 | 다운로드 파일 |
| --- | --- | --- | --- |
| 선발 | 20명 | 1~20명 | `random-bgb-selected.png` |
| 예비 | 10명 | 0~10명 | `random-bgb-reserve.png` |

중복을 제외한 전체 인원은 선발·예비 인원의 합계 이상이어야 합니다. 인원이 부족하거나 설정 범위를 벗어나면 안내 메시지가 표시됩니다.

각 명단의 번호는 이름순으로 정렬한 표시 순서입니다. 다시 **랜덤 뽑기**를 누르면 새로 추첨하며, 명단이나 인원 설정을 수정하면 기존 결과가 초기화됩니다. 추첨 전과 예비 인원이 0명일 때는 해당 이미지 다운로드 버튼이 비활성화됩니다.

## 임시 저장

명단과 인원 설정은 브라우저의 `sessionStorage`에 저장됩니다. 같은 탭에서 새로고침하면 복원되며, 탭의 세션이 종료되면 임시 저장도 종료됩니다. 추첨 결과는 새로고침 후 다시 뽑아야 합니다.

입력한 명단은 브라우저 안에서 처리됩니다. 브라우저가 임시 저장을 차단하면 화면에 안내가 표시되며, 새로고침 시 입력 내용이 사라질 수 있습니다.
